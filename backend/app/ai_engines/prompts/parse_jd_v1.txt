Return only valid JSON with this shape:
{
  "title": "Job title",
  "status": "open",
  "employment_type": "Internship",
  "location": "Hybrid",
  "salary_range": "Competitive",
  "benefits": ["Mentorship"],
  "skills": {
    "skill_name": {
      "required_level": 0.0,
      "importance": 0.0,
      "required": true
    }
  }
}

Rules:
- Normalize skill names to lowercase.
- Required level is from 0 to 10.
- Importance is from 0 to 1.

- Do not include markdown fences or explanatory text.
